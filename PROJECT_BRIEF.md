# Project brief

Version **0.3.1** · 2026-09-20 · Creator/producer: **Ritsu**.

## Purpose

A small, illustrated Lake Suwa notebook for exploring historical Omiwatari (御神渡り) records, uncertain evidence, and the lake's cultural context. It should be warm and playful without turning gaps into facts or historical proportions into forecasts.

## Current baseline

The third local website edition plus general-audience copy and English repository documentation. Interface language: Traditional Chinese. Runtime: static HTML/CSS/JavaScript, with optional loopback Python RSS service. No live LLM/image API, public deployment, or scheduled job. The private repository is `RitsuTsao/suwa-winter-notebook`.

Read [README.md](README.md), [CREDITS.md](CREDITS.md), [RESEARCH.md](RESEARCH.md), and [VERIFICATION.md](VERIFICATION.md) before continuing work. The data snapshot is 2026-09-20: 150 winters; 119 known annual outcomes; 31 unknown; 27 accepted precise appearance dates; no reliable continuous visibility intervals.
